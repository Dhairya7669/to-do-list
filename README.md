✅ To-Do List Webpage

This project is a personal To-Do List website created using HTML and CSS.
It visually separates tasks into three clear categories:

📌 Sections Included

To-Do – Tasks that need to be completed

In Progress – Tasks currently being worked on

Done – Completed tasks

Each item includes an emoji indicator for better readability.

🎨 Features

Clean and organized layout

Background image for a modern, modern look

CSS pseudo-selectors implemented

Well-structured HTML with proper semantics

Attractive and responsive styling

💡 Learning Goals

This project demonstrates:

How to structure a webpage using semantic HTML

Styling using CSS hierarchy

Understanding the cascade and selector rules

Organizing and maintaining code cleanly

Using GitHub (branches, commits, pull requests, merging) effectively
